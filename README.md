This is our college Big Data Analytics project. It is a Big Data project. Basically, what we have done is, we took the MovieLens movie ratings dataset, and we analyzed it using lots of Hadoop tools to find out some interesting stuff about movies, users, and genres.

We used these things:

HDFS — this is where we kept all our data (it's like a distributed file system)
Java MapReduce — this we used to find rating statistics for every movie
Python Hadoop Streaming — this we used to find the most active users
Apache Hive — this we used to run SQL type queries on the data
